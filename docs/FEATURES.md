# RuneScape Dragonwilds Survival Toolkit — feature reference

The RuneScape Dragonwilds survival toolkit workflow separates resource groups from exploration notes and session planning. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Resource groups | Inventory and resource categories organized alongside their related values and notes. |
| Exploration notes | A dedicated section for exploration notes and the configuration details associated with that area. |
| Session planning | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
